# Superstars

The **Superstars** list is a curated set of prominent GitHub accounts. The pun is intentional: these are people whose star can act like a "super star" for a project.

The list is not meant to be objective, complete, or permanent. It should be useful, explainable, and easy to debate in public.

## Suggesting Changes

Open a pull request that edits [`data/superstars.json`](./data/superstars.json).

Each entry should include:

```json
{
  "login": "example",
  "name": "Example Person",
  "blurb": "Short reason this account is notable"
}
```

Good blurbs are short enough to fit in a badge and describe why the account is notable, for example:

```text
Creator of Ruby
React core alum and educator
Prolific open source maintainer
AI educator and neural networks researcher
```

## What Counts?

The list can include prominent people in tech generally, not only open source maintainers. Strong candidates usually have at least one of these:

- created or maintained widely used software
- shaped a major developer ecosystem
- founded or led influential technical organizations
- produced widely read technical writing, research, or education
- earned broad recognition from developers

This is intentionally subjective. If a name is debatable, the pull request discussion is the right place to make the case.

## Naming

"Superstars" is a working name. Suggestions are welcome via pull request, especially names that preserve the idea of a star from a high-signal account without sounding too stiff.
